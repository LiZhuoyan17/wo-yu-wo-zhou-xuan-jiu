# 我与我周旋久

李琢言的游戏设计作业：**我与我周旋久——一段与自己和好的旅途**。

本仓库收录桌面文件夹“我与我周旋久——李琢言作业”中的游戏工程、演示文稿与讲稿。

## 文件说明

- `我与我周旋久/`：从原始代码压缩包解压的 Godot 游戏工程，含脚本、场景和素材。
- `作业资料/`：PPTX 演示文稿，以及 DOCX、Markdown、TXT 三种格式的按页对照讲稿。
- [完整原始文件下载](https://github.com/LiZhuoyan17/wo-yu-wo-zhou-xuan-jiu/releases/tag/v1.0.0)：原始代码 ZIP 与演示 MP4，保留原文件内容。

## 打开工程

在 Godot 中导入 `我与我周旋久/project.godot`，待资源导入完成后运行项目。工程配置标记为 Godot 4.7，默认启动场景为 `scenes/opening_intro.tscn`。

## 原始附件

Release 使用英文文件名便于下载，对应关系如下：

- `wo-yu-wo-zhou-xuan-jiu-full-source.zip`：原文件“我与我周旋久-全套代码.zip”。
- `wo-yu-wo-zhou-xuan-jiu-demo.mp4`：原文件“我与我周旋久——李琢言.mp4”。

原始代码包中还包含一个约 216 MB 的 `.NET SDK` 安装程序，路径为 `我与我周旋久/assets/tiles/background/far/dotnet-sdk-10.0.400-win-x64.exe`。该文件保留在 Release 的完整 ZIP 中，未纳入 Git 文件，以符合 GitHub 单文件大小限制。

本次整理仅用于上传与归档，未修改游戏逻辑，未验证游戏运行效果。
