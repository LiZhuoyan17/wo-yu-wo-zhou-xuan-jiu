# 《我与我周旋久》按键效果报告

> 状态机（IDLE/RUN/JUMP/FALL/ATTACK/HURT/REWIND）未改，仅优化 InputMap。

---

## 一、优化后的最终键位

| 功能 | 动作名 | 按键 | 效果说明 |
|------|--------|------|----------|
| 左右移动 | `ui_left` / `ui_right` | **A / D** 或 **← / →** | 水平移动；魅惑时方向反转 |
| 上下瞄准 | `ui_up` / `ui_down` | **W / S** 或 **↑ / ↓** | 配合发射做斜向/垂直射击（不单独跳跃） |
| 跳跃 | `ui_accept` | **空格 Space** | 起跳；魅惑时可触发一次跃升冲量 |
| 平 A 冲刺 | `attack` | **J** | 进入 ATTACK，短距冲刺+近战；空中狐妖免疫平 A |
| 发射魔法球 | `shoot_orb` | **L** 或 **鼠标右键** | 耗蓝发射；可配合 WASD/方向键斜向、垂直发射 |
| 影子回溯 | `rewind` | **K** | 回到数秒前位置并留下实体影子 |
| 暂停/继续 | `ui_cancel` | **Esc** | 暂停；死亡时 Esc 可重置关卡 |

### 斜向发射组合（发射键 = L 或右键）

| 组合 | 弹道 |
|------|------|
| 只按发射 | 水平（当前朝向） |
| 发射 + W/↑ | 竖直向上 |
| 发射 + S/↓ | 竖直向下 |
| 发射 + W+D 等 | 对角线 |

## 二、原先的冲突（已处理）

| 冲突 | 原因 | 问题表现 | 处理 |
|------|------|----------|------|
| **W = 跳跃** | `ui_accept` 绑了 W | 按 W 想抬头瞄准却先跳起来；斜射狐狸很难用 | 跳跃改为**仅空格**；W 专供向上瞄准 |
| **H 紧挨 J** | 发射 H、平 A 为 J | 右手食指易误触：想射却冲刺，或想砍却放球 | 发射改为 **L**（J/K/L 一排：砍/回溯/射） |
| **上下瞄准缺失** | 未明确绑 `ui_up`/`ui_down` 到 WASD | 斜向攻击只能靠方向键，和 WASD 移动割裂 | 补上 **W/S + ↑/↓** |

未改动的合理设计（不算冲突）：
- **空格跳跃** 与 **移动** 左右手分工，保留。
- **K 回溯** 与战斗键相邻但功能独立，保留。
- **Esc 暂停** 与玩法键无重叠，保留。

---

## 三、推荐指法（手感）

```
左手：WASD 移动/瞄准     拇指：空格跳跃
右手：J 平A  K 回溯  L 发射（或鼠标右键发射）
```

打半空狐狸：按住 **W + D**（或 W + 朝向），再点 **L / 右键**。

---

## 四、与状态机的关系（确认未破坏）

| 输入 | 是否改状态 | 说明 |
|------|------------|------|
| 移动 A/D | 可能 IDLE↔RUN | 原有逻辑 |
| 空格 | 可能 → JUMP | 原有逻辑；W 不再触发 |
| J | → ATTACK | 原有冲刺平 A |
| L/右键 | **不改状态** | 仅发射，可在跑/跳中使用 |
| K | 短暂 REWIND 流程 | 原有回溯 |
| Esc | GameManager 暂停 | 与角色状态机独立 |

---

## 五、快速自测清单

1. 只按 **W**：不应跳跃，只用于瞄准。  
2. **空格**：正常跳。  
3. **J**：冲刺平 A；**L**：出暖黄球（不要再出在 H）。  
4. **W+L**：球向上飞，可打狐狸。  
5. **K**：回溯留影；怪会追影子。  
6. **Esc**：暂停/继续。
